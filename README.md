# Risup Editor

Windows x64용 로컬 RisuAI 프리셋 편집기입니다. 배포 실행 파일은 `artifacts/release/RisupEditor.exe` 하나입니다. 설치나 별도 .NET 설치 없이 실행하도록 런타임을 포함합니다. 최초 실행 시 .NET이 일부 네이티브 구성 요소를 임시 폴더에 해제할 수 있습니다.

## 사용법

Ctrl+F는 마지막으로 선택한 구역에서 검색합니다. 참조 프리셋은 현재 탭, 작업 중은 블록·토글·정규식·기타 전체, 채팅 화면 토글은 이름·선택지·입력값을 검색합니다. 미리보기 중에는 미리보기를 닫지 않고 화면에 실제 표시된 최종 텍스트를 검색합니다. 접힌 결과는 이동할 때 펼쳐지고 현재 결과는 선명한 노란색으로 표시됩니다. Enter/Shift+Enter로 다음/이전 결과로 이동하고 Esc로 검색창을 닫습니다. 검색은 대소문자를 구분하지 않으며 원문이나 토글 선택값을 변경하지 않습니다.

하단 공통 도구줄의 `화면 기본값 복원`은 구역 비율을 40:40:20으로 되돌립니다. `추가 문법 검사`는 기본적으로 꺼져 있으며 켜면 일반 태그의 짝 등 의도적일 수 있는 표현도 노란 안내로 표시합니다. 기본 CBS 구조 진단은 빨간 밑줄로 표시하고 마우스를 올리면 설명을 볼 수 있습니다. 검사 기준과 범위는 `CBS_DIAGNOSTICS.md`에 정리했습니다.

현재 화면은 `참조 프리셋` 40%, `작업 중` 40%, `채팅 화면 토글` 20%의 3분할 구조입니다. 창을 줄이면 상단 버튼은 가려지지 않고 다음 줄로 이동합니다. 왼쪽의 블록·토글·정규식 복사 버튼은 현재 내용을 지우지 않고 참조 값을 작업 중 영역 끝에 추가합니다. `기타 정보 덮어쓰기 →`만 확인 후 모델·생성 설정 등 기타 필드를 교체하며 블록·토글·정규식은 유지합니다. 참조와 작업 중에는 `프롬프트 블록 → 토글 → 정규식 → 기타` 순서로 표시되며, 각 제목 왼쪽의 고정 크기 `접기`/`펼치기` 버튼으로 영역 전체를 접을 수 있습니다. 작업 중에서는 네 영역을 편집할 수 있고, 오른쪽에는 실제 채팅 화면 형태의 토글 조작 UI만 표시됩니다. 기타는 promptTemplate, customPromptTemplateToggle, regex를 제외한 필드이며 바이너리와 확장 값도 보존합니다. 모든 복사·덮어쓰기 작업은 실행 취소할 수 있습니다.

1. 왼쪽 **참조 프리셋**의 **불러오기**를 누르고 `.risup` 또는 `.risupreset` 파일을 선택합니다. 여러 파일을 한 번에 선택할 수 있습니다.
2. 왼쪽 **참조 프리셋**에서 탭을 선택합니다. 내용은 읽기 전용이며 선택한 텍스트를 Ctrl+C로 복사할 수 있습니다.
3. **블록 전체 복사 →**로 현재 탭의 모든 블록을, **블록 복사 →**로 선택한 블록 하나를 **작업 중**에 추가합니다. 기존 블록과 토글·정규식·기타는 건드리지 않습니다.
4. 가운데 **작업 중**에서 내용을 수정합니다. 블록을 펼치면 RisuAI와 같은 흐름으로 **이름 → 타입 → 특수 타입 → 본문 → 역할**이 표시되며, 타입별로 필요하지 않은 항목은 숨겨집니다. 점 모양 손잡이 또는 ↑/↓로 순서를 바꾸고, ⧉로 복제하고, ×로 삭제합니다. 텍스트 입력부 밖의 블록을 누르면 접거나 펼칠 수 있습니다.
5. **토글 복사 →**와 **정규식 복사 →**는 참조 값을 기존 작업 끝에 추가합니다. **기타 정보 덮어쓰기 →**는 확인 후 기타 설정만 교체합니다. 오른쪽 **채팅 화면 토글**은 정의된 checkbox, select, text, textarea, group, groupEnd, caption, divider를 RisuAI의 해석 방식대로 표시합니다. 알 수 없는 타입은 RisuAI처럼 기본 체크박스로 처리하며, RisuAI가 무시하는 비어 있지 않은 줄만 행 번호와 함께 안내합니다. 커스텀 토글의 CRLF/CR 줄바꿈은 작업·프로젝트 저장·내보내기 과정에서 LF로 통일해 RisuAI의 group/groupEnd 인식 오류를 방지합니다.
6. 작업 중 도구줄의 가장 오른쪽에 있는 **With Join ☐  미리보기** 묶음에서 체크박스를 끄면 RisuAI의 `Preview Prompt`에서 `Type: Chat`, `Join: Without Join`을 선택한 구조를 표시하고, 켜면 연속된 같은 역할의 메시지를 합칩니다. 미리보기 버튼은 활성 상태에서만 같은 크기의 강조 테두리를 유지합니다. 미리보기 본문은 드래그 선택과 복사가 가능하며 `{{user}}`, `{{char}}`, `{{maxcontext}}`, `{{roll::...}}`은 각각 색으로 구분됩니다. Ctrl+F는 최종 미리보기 안에서 검색합니다.
7. **저장**은 참조 탭, 작업 중 블록·토글·정규식·기타, 시험용 토글 값, 개별 블록과 각 상위 영역의 접힘 상태, 선택·미리보기 및 With Join 상태, 화면 비율과 추가 문법 검사 설정을 `.risupproj`로 보관합니다. **프로젝트 불러오기**로 이어서 작업할 수 있습니다. 검색 결과가 접힌 영역 안에 있으면 해당 영역을 자동으로 펼칩니다.
8. **내보내기**에서 RisuAI에 표시할 프리셋 이름과 위치를 지정해 `.risup` 파일로 저장합니다.

블록·토글·정규식·기타는 서로 독립적으로 작업되며 내보낼 때 하나의 프리셋으로 합쳐집니다. 모델·생성 설정까지 참조 프리셋과 맞추려면 **기타 정보 덮어쓰기 →**를 사용하세요. 빈 작업에서 내보낼 때는 현재 열린 참조 프리셋의 컨테이너 형식만 기준으로 사용하며, 참조 프리셋이 하나도 없으면 내보낼 수 없습니다.

미리보기는 RisuAI의 중첩 CBS 인수와 조건 블록을 해석하며, 비교·논리·문자열·배열·수치 등 프리셋만으로 결과가 정해지는 함수를 계산합니다. description·persona·memory·authornote는 RisuAI와 같은 순서로 `innerFormat`의 CBS를 먼저 처리한 다음 첫 `{{slot}}`에 실제 내용의 자리를 넣습니다. 현재 캐릭터·로어북·대화·시간·난수·모듈 및 Lua `editRequest`처럼 실행 중인 RisuAI 상태가 필요한 값만 색이 있는 원문이나 자리 안내로 남깁니다. 자리 안내는 미리보기 전용이며 원문이나 내보내기 결과를 변경하지 않습니다. 정확한 구분은 `PREVIEW_COMPATIBILITY.md`에 공개되어 있습니다.

- Ctrl+O: 불러오기
- Ctrl+S: 프로젝트 저장
- Ctrl+Z / Ctrl+Y: 실행 취소 / 다시 실행
- 새 작업 및 종료 시 내보내지 않은 변경을 확인합니다.
- 세 구역의 초기 너비는 40:40:20이며 두 세로 손잡이로 조절할 수 있습니다.

## 지원 범위

- `.risup`: RPack + gzip/zlib/raw deflate + MessagePack + AES-GCM 프리셋.
- `.risupreset`: RPack을 사용하지 않는 같은 프리셋 컨테이너.
- 외부 컨테이너의 presetVersion 0과 2를 지원합니다.
- 블록형 promptTemplate이 없는 구형 프리셋은 설명을 표시하며 자동 변환하지 않습니다.
- 알 수 없는 블록 및 프롬프트 외의 필드, 바이너리/확장 값은 보존합니다.
- 잘린 파일, 지원하지 않는 버전, 지나친 중첩 및 64MB 초과 파일/압축 해제 데이터는 거부합니다.
- 파일을 임시 파일에 완성한 뒤 대상에 반영합니다. 기존 파일 덮어쓰기는 저장 대화상자에서 확인합니다.

## 빌드

프로젝트 폴더 내 `tools/dotnet`에 .NET SDK 8.0.425가 준비되어 있습니다.

```powershell
.\build.ps1            # 개발 빌드
.\build.ps1 -Publish   # 단일 exe: artifacts/release
```

프로젝트는 WPF/C#이며 앱 자체에 외부 NuGet 패키지를 사용하지 않습니다. 빌드 스크립트는 SDK 사용자 데이터, NuGet 캐시, 임시 파일 위치를 프로젝트의 tools 폴더로 지정합니다. 소스는 `src`에 있습니다.

## 검증

```powershell
node .\tests\format-test.mjs --ui
```

테스트는 msgpackr 1.10.1의 브라우저 배포본과 fflate 0.8.2로 RisuAI의 프리셋 입출력 로직에 맞는 파일을 생성하고, C# 앱에서 다시 저장한 파일을 독립적으로 해독해 비교합니다. Node의 오래된 Buffer API 호환 문제를 피하고자 브라우저 배포본을 격리 환경에서 실행합니다. 검증 라이브러리는 tests/vendor에 포함되어 npm 설치가 필요 없습니다.

검증 내용: 일반/구형/압축 방식별 파일, 텍스트·순서 수정, 한국어·변수·이모지 보존, 미지의 필드·날짜·바이너리·undefined·BigInt 보존, 손상/미지원 파일 거부, 실제 WPF TextBox 수정, 10개 참조 탭의 한 줄 배치, 복사/이동/복제/삭제/실행 취소/다시 실행, 프로젝트 왕복, 커스텀 토글 미리보기 및 내보내기. 미리보기 엔진은 checkbox/select/text 토글, 중첩 CBS, 실행 시점 조건 보존, ChatML, `{{slot}}` 자리 안내, cache, COT, post-end와 system 메시지 병합을 별도로 검사합니다.

실제 사용자의 프리셋 파일 및 실행 중인 RisuAI UI에서의 수동 가져오기는 아직 검증하지 않았습니다. 테스트 파일은 합성 자료이며 실제 채팅이나 사용자 데이터를 포함하지 않습니다.
