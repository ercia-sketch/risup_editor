# Risup Editor

Windows x64용 로컬 RisuAI 프리셋 편집기입니다. 배포 실행 파일은 `artifacts/release/RisupEditor.exe` 하나입니다. 설치나 별도 .NET 설치 없이 실행하도록 런타임을 포함합니다. 최초 실행 시 .NET이 일부 네이티브 구성 요소를 임시 폴더에 해제할 수 있습니다.

## 사용법

Ctrl+F는 마지막으로 선택한 구역에서 검색합니다. 참조 프리셋은 현재 탭, 작업 중은 블록·토글 정의·기타 정보 전체, 채팅 화면 토글은 이름·선택지·입력값을 검색합니다. 접힌 결과는 이동할 때 펼쳐집니다. Enter/Shift+Enter로 다음/이전 결과로 이동하고 Esc로 검색창을 닫습니다. 검색은 대소문자를 구분하지 않으며 원문이나 토글 선택값을 변경하지 않습니다. `블록 전체 복사`는 현재 참조 탭의 프롬프트 블록만 추가합니다.

하단 공통 도구줄의 `화면 기본값 복원`은 구역 비율을 40:40:20으로 되돌립니다. `추가 문법 검사`는 기본적으로 꺼져 있으며 켜면 일반 태그의 짝 등 의도적일 수 있는 표현도 노란 안내로 표시합니다. 기본 CBS 구조 진단은 빨간 밑줄로 표시하고 마우스를 올리면 설명을 볼 수 있습니다. 검사 기준과 범위는 `CBS_DIAGNOSTICS.md`에 정리했습니다.

현재 화면은 `참조 프리셋` 40%, `작업 중` 40%, `채팅 화면 토글` 20%의 3분할 구조입니다. 왼쪽의 `블록 전체 복사 →`, `블록 복사 →`는 현재 참조 탭의 프롬프트 블록을 가운데 작업 영역에 추가합니다. `토글 덮어쓰기 →`, `기타 정보 덮어쓰기 →`는 각각 해당 영역 전체를 현재 참조 값으로 교체하며 실행 취소할 수 있습니다. 참조와 작업 중 블록 아래에는 Toggle Config 및 Other Fields가 표시됩니다. 작업 중에서는 두 영역을 편집할 수 있고, 오른쪽에는 실제 채팅 화면 형태의 토글 조작 UI만 표시됩니다. Other Fields는 promptTemplate과 customPromptTemplateToggle을 제외한 필드입니다. 바이너리와 확장 값은 읽기 전용으로 표시하면서 원본을 유지합니다. `현재 작업 삭제`는 참조 탭과 디스크의 프로젝트 파일을 유지한 채 현재 편집 상태만 비우며, 실행 취소로 복원할 수 있습니다. CBS·태그·제목 문법은 원문 변경 없이 배경색과 진단 밑줄로 표시합니다.

1. 왼쪽 **참조 프리셋**의 **불러오기**를 누르고 `.risup` 또는 `.risupreset` 파일을 선택합니다. 여러 파일을 한 번에 선택할 수 있습니다.
2. 왼쪽 **참조 프리셋**에서 탭을 선택합니다. 내용은 읽기 전용이며 선택한 텍스트를 Ctrl+C로 복사할 수 있습니다.
3. **블록 전체 복사 →**로 현재 탭의 모든 블록을, **블록 복사 →**로 선택한 블록 하나를 **작업 중**에 추가합니다. 기존 블록은 지우지 않으며 Toggle Config와 Other Fields도 함께 복사하지 않습니다.
4. 가운데 **작업 중**에서 내용을 수정합니다. 점 모양 손잡이 또는 ↑/↓로 순서를 바꾸고, ⧉로 복제하고, ×로 삭제합니다. 텍스트 입력부 밖의 블록을 누르면 접거나 펼칠 수 있습니다.
5. 가운데 작업 영역 하단의 **Toggle Config**에서 토글 정의 원문을 편집합니다. 왼쪽의 **토글 덮어쓰기 →**를 누르면 현재 참조 프리셋의 정의로 전체 교체됩니다. 오른쪽 **채팅 화면 토글**은 정의된 checkbox, select, text, textarea, group, groupEnd, caption, divider를 실제 조작 UI에 가깝게 표시합니다.
6. **미리보기**는 RisuAI의 `Preview Prompt`에서 `Type: Chat`, `Join: Without Join`을 선택한 구조에 맞춰 현재 블록과 오른쪽 채팅 화면 토글 값을 역할별 메시지 카드로 표시합니다. ChatML 분해, jailbreak/COT 활성화, 연속 system 메시지 병합, cache 지점과 주요 토글 CBS를 반영합니다. 캐릭터 설명·로어북·페르소나·메모리·채팅 기록처럼 편집기에 실제 데이터가 없는 부분은 주변 형식을 유지한 채 색이 다른 자리 안내로 표시됩니다.
7. **저장**은 참조 탭, 작업 중 블록, 기준 프리셋 데이터, Toggle Config, 시험용 토글 값, 접힘·선택·미리보기 상태, 화면 비율과 추가 문법 검사 설정을 `.risupproj`로 보관합니다. **프로젝트 불러오기**로 이어서 작업할 수 있습니다.
8. **내보내기**에서 RisuAI에 표시할 프리셋 이름과 위치를 지정해 `.risup` 파일로 저장합니다.

첫 복사에 사용한 프리셋의 모델·생성 설정 등을 자동으로 유지합니다. 빈 작업에서 새 블록만 만든 경우에는 현재 열려 있는 참조 프리셋을 사용합니다. 참조 프리셋이 하나도 없으면 내보낼 수 없습니다.

미리보기는 커스텀 토글과 관련된 `getglobalvar`, 중첩 `#if`, `#when`, `toggle`, `tis`, `tisnot`, 논리·비교 구문을 반영합니다. 런타임 캐릭터 변수나 RisuAI 전체 파서가 필요한 CBS는 결과를 임의로 추측하지 않고 원문과 제한 안내를 표시합니다. 실제 캐릭터·로어북·대화 데이터, 모듈 및 Lua `editRequest` 결과는 읽지 않으므로 해당 부분은 자리 안내로 표시됩니다. 자리 안내는 미리보기 전용이며 원문이나 내보내기 결과를 변경하지 않습니다.

- Ctrl+O: 불러오기
- Ctrl+S: 프로젝트 저장
- Ctrl+Z / Ctrl+Y: 실행 취소 / 다시 실행
- 새 작업 및 종료 시 내보내지 않은 변경을 확인합니다.
- 세 구역의 초기 너비는 40:40:20이며 두 세로 손잡이로 조절할 수 있습니다.

## 지원 범위

- `.risup`: RPack + gzip/zlib/raw deflate + MessagePack + AES-GCM 프리셋.
- `.risupreset`: RPack을 사용하지 않는 같은 프리셋 컨테이너.
- 외부 컨테이너의 presetVersion 0과 2를 지원합니다.
- 블록형 promptTemplate이 없는 구형 프리셋은 설명을 표시하며 자동 변환하지 않습니다.
- 알 수 없는 블록 및 프롬프트 외의 필드, 바이너리/확장 값은 보존합니다.
- 잘린 파일, 지원하지 않는 버전, 지나친 중첩 및 64MB 초과 파일/압축 해제 데이터는 거부합니다.
- 파일을 임시 파일에 완성한 뒤 대상에 반영합니다. 기존 파일 덮어쓰기는 저장 대화상자에서 확인합니다.

## 빌드

프로젝트 폴더 내 `tools/dotnet`에 .NET SDK 8.0.425가 준비되어 있습니다.

```powershell
.\build.ps1            # 개발 빌드
.\build.ps1 -Publish   # 단일 exe: artifacts/release
```

프로젝트는 WPF/C#이며 앱 자체에 외부 NuGet 패키지를 사용하지 않습니다. 빌드 스크립트는 SDK 사용자 데이터, NuGet 캐시, 임시 파일 위치를 프로젝트의 tools 폴더로 지정합니다. 소스는 `src`에 있습니다.

## 검증

```powershell
node .\tests\format-test.mjs --ui
```

테스트는 msgpackr 1.10.1의 브라우저 배포본과 fflate 0.8.2로 RisuAI의 프리셋 입출력 로직에 맞는 파일을 생성하고, C# 앱에서 다시 저장한 파일을 독립적으로 해독해 비교합니다. Node의 오래된 Buffer API 호환 문제를 피하고자 브라우저 배포본을 격리 환경에서 실행합니다. 검증 라이브러리는 tests/vendor에 포함되어 npm 설치가 필요 없습니다.

검증 내용: 일반/구형/압축 방식별 파일, 텍스트·순서 수정, 한국어·변수·이모지 보존, 미지의 필드·날짜·바이너리·undefined·BigInt 보존, 손상/미지원 파일 거부, 실제 WPF TextBox 수정, 10개 참조 탭의 한 줄 배치, 복사/이동/복제/삭제/실행 취소/다시 실행, 프로젝트 왕복, 커스텀 토글 미리보기 및 내보내기. 미리보기 엔진은 checkbox/select/text 토글, 중첩 CBS, 미지원 런타임 조건 보존, ChatML, `{{slot}}` 자리 안내, cache, COT, post-end와 system 메시지 병합을 별도로 검사합니다.

실제 사용자의 프리셋 파일 및 실행 중인 RisuAI UI에서의 수동 가져오기는 아직 검증하지 않았습니다. 테스트 파일은 합성 자료이며 실제 채팅이나 사용자 데이터를 포함하지 않습니다.
